# PLANO-INFORMATIVO-PARA-UBICACION-DE-PREDIOS
# Consultoría y Publicidad BH – Aplicación de Planos

Aplicación desarrollada en **Streamlit** para importar y exportar planos de predios en formatos Shapefile y DWG/DXF, con generación automática de PDF corporativo y KMZ.

## Funcionalidades
- Importar Shapefile y DWG/DXF
- Convertir DWG a Shapefile
- Exportar PDF con portada corporativa y cuadro de construcción
- Exportar KMZ con Excel estilizado y gráfico del polígono
- Interfaz con logotipo, colores corporativos, WhatsApp y correo electrónico
